ÉTAPE 2 — RAPPORTS INVITÉS
━━━━━━━━━━━━━━━━━━

PROBLÈME :
Un utilisateur peut générer un rapport sans compte.
Après login/signup :
- le rapport disparaît
- ou n’est pas sauvegardé
- ou n’est pas attaché au compte.

SOLUTION À IMPLÉMENTER :

A. Avant login
Quand un rapport IA est généré :
- sauvegarder automatiquement dans localStorage :
  - report content
  - images
  - timestamp
  - temporary guest id

Créer :
guest_reports

Structure :
{
  id,
  createdAt,
  reportData,
  images,
  synced:false
}

B. Après login/signup
Au moment du succès auth :
- détecter rapports guest
- envoyer automatiquement au backend
- créer rapports permanents DB
- attacher au userId connecté
- marquer synced:true
- nettoyer localStorage seulement après succès

IMPORTANT :
- aucun rapport ne doit être perdu
- supporter refresh navigateur
- supporter plusieurs rapports
- éviter doublons

Ajouter :
- retry simple
- gestion erreur réseau
- logs console clairs
